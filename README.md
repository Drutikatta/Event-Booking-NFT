# 🎟️ NFT-Based Decentralized Event Ticket Booking System

A blockchain-powered decentralized event ticket booking platform where tickets are minted as NFTs using the Ethereum blockchain. The system ensures secure ticket ownership, prevents fraud and duplication, and enables transparent ticket verification and transfer using smart contracts.

## 🚀 Features

🔗 Blockchain-based decentralized ticketing
- 🎫 NFT ticket generation using ERC-721 standard
- 🛡️ Fraud-proof and duplicate-free tickets
- 👛 MetaMask wallet integration
- 📜 Smart contract-based ticket ownership verification
- 🔄 Secure ticket transfer & resale
- ⚡ Real-time blockchain transaction recording
- ✅ Event entry verification using NFT ownership
- 🖥️ Admin dashboard for managing events and tickets
- 🌐 DApp-based frontend interface

## 📌 Problem Statement

Traditional event ticket booking systems suffer from:

- Fake and duplicate tickets
- Ticket scalping and black-market resale
- Lack of ownership verification
- Centralized control and security risks
- Manual ticket validation delays

This project solves these issues using blockchain technology and NFTs to provide a secure, transparent, and decentralized ticketing solution.

---

## ⚙️ How the System Works

1. User opens the DApp
2. Connects MetaMask wallet
3. Selects an event
4. Purchases ticket through blockchain transaction
5. Smart contract mints NFT ticket
6. NFT ticket is transferred to user wallet
7. Ownership is recorded on blockchain
8. Ticket can be securely transferred/resold
9. NFT ownership is verified during event entry

## ▶️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/event-ticket-booking-system.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd event-ticket-booking-system
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start Ganache

Run Ganache locally for blockchain testing.

### 5️⃣ Deploy Smart Contracts

```bash
truffle migrate
```

### 6️⃣ Run the Project

This project runs using a local HTTP server.

```bash
npx http-server
```

After running the command, open the localhost link shown in the terminal in your browser.
